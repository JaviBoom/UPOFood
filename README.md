# UPOFood

Trabajo de la asignatura de patrones de diseño (curso 22/23) en la UPO. Es un programa en Java para llevar una tienda de comida rápida con varios tipos de comida, y la gracia del trabajo era meter varios patrones de diseño a la vez y que encajaran bien entre ellos.

Lo que hay en el repo:

- `UPOFood/`: el código del proyecto
- `UMLPatrones_22_23.png`: el diagrama UML
- `Documento_proyecto_patrones_22_23.docx`: la memoria del proyecto
